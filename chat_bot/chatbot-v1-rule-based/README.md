# Chatbot V1 - Rule Based Chatbot

A simple rule-based chatbot built with Python.

This project was created as part of my AI learning journey to understand the fundamentals of chatbot development before moving on to NLP, Machine Learning, and LLM-based chatbots.

## Features

- User name recognition
- Greeting responses
- Basic conversation handling
- Message counter
- Exit command support
- Simple and beginner-friendly code structure

## Technologies Used

- Python
- Functions
- Loops
- Conditional Statements
- String Operations

## Example

Bot: What's your name?
You: Emir

Bot: Nice to meet you, Emir!
Bot: Hello! Type 'bye' to exit.

You: hello
Bot: Hi!

You: thanks
Bot: You're welcome!

You: bye
Bot: Goodbye Emir! We exchanged 3 messages.

## Learning Goals

This project focuses on:

- Python fundamentals
- Rule-based chatbot logic
- User input processing
- Program flow control
- Building interactive terminal applications
