# Chatbot V2 - Intent Detection Chatbot

A simple intent-based chatbot built with Python.

This project was created as the second step of my AI learning journey. Unlike the first version, this chatbot separates intent detection from response generation, creating a more scalable chatbot architecture.

## Features

- User name recognition
- Intent detection system
- Greeting intent support
- Status question intent support
- Thanks intent support
- Goodbye intent support
- Random greeting responses
- Message counter
- Exit command support
- Modular code structure

## Technologies Used

- Python
- Functions
- Loops
- Conditional Statements
- Lists
- Return Statements
- For Loops
- Random Module
- Intent Detection Logic

## Example

Bot: What's your name?
You: Emir

Bot: Nice to meet you, Emir!
Bot: Hello! Type 'bye' to exit.

You: hi bot
Bot: Hello!

You: how are you
Bot: I'm doing well!

You: thank you
Bot: You're welcome!

You: bye
Bot: Goodbye Emir! We exchanged 4 messages.

## Learning Goals

This project focuses on:

- Intent Detection
- Program Architecture
- Separating Logic and Responses
- Function Design
- User Input Processing
- Building More Scalable Chatbots

## V1 vs V2

### V1

User Message → Response

### V2

User Message → Intent Detection → Response

This architecture prepares the chatbot for future Machine Learning and NLP integrations.
