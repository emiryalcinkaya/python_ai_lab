# Chatbot V4 - LLM Chatbot

A chatbot powered by Llama 3 and Ollama.

This project is the fourth step in my AI learning journey. Unlike previous versions that relied on rules, intent detection, or machine learning classification, this chatbot uses a Large Language Model (LLM) to generate responses and maintain conversation history.

## Project Evolution

### V1 - Rule Based Chatbot
User Message → Response

### V2 - Intent Detection Chatbot
User Message → Intent Detection → Response

### V3 - Machine Learning Chatbot
User Message → ML Model → Intent Prediction → Response

### V4 - LLM Chatbot
User Message → Llama 3 → Generated Response

## Features

- Llama 3 integration through Ollama
- Conversation history support
- Context-aware responses
- Message counter
- Interactive terminal chat
- Local AI model execution

## Technologies Used

- Python
- Ollama
- Llama 3
- Lists & Dictionaries
- Loops
- Functions

## How It Works

User Message       
↓ 
Conversation History       
↓ 
Llama 3       
↓ 
Generated Response 

The chatbot stores previous messages and sends the entire conversation history to the model, allowing it to remember context during the chat.

## Example Session

You: My name is Emir. 
Bot: Nice to meet you, Emir.  
You: What is my name?  
Bot: Your name is Emir.
